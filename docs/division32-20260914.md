# September 14: 32-bit division candidate

The translated DIV/IDIV helpers now use 32-bit software division when EDX:EAX
contains an ordinary zero-extended or sign-extended 32-bit dividend. Wider
inputs retain 64-bit division. This is a translation-layer candidate; no Vita
frame-rate improvement has been measured for it.

Unsigned quotient overflow is checked before division. Signed division also
checks INT64_MIN divided by -1 before executing a C division, avoiding undefined
behavior and reporting the guest divide exception. Divide-by-zero and quotient
overflow preserve the incoming guest context before the trap. Successful calls
change EAX and EDX only; guest flags and floating-point state remain untouched.

## Validation

- 408,194 independent integer-magnitude oracle cases pass on the host and under
  AddressSanitizer/UndefinedBehaviorSanitizer. They check the full guest context,
  trap count/address/context and native FP exception flags, including both
  narrow and wide dividends, quotient boundaries, signs and seeded random inputs.
- 19,199 compiled ARM executions pass full-context and trap checks. This covers
  9,600 candidate cases and 9,599 preceding-helper comparisons; the preceding
  helper's undefined INT64_MIN / -1 case is excluded from that reference run.
- The standard host runtime suite passes with the new division test included.

| Successful synthetic cases | Previous mean ARM instructions | Candidate mean |
| --- | ---: | ---: |
| Unsigned narrow (1,641 cases) | 67.56 | 38.21 |
| Signed narrow (1,640 cases) | 77.72 | 47.14 |
| Unsigned wide (1,170 cases) | 287.91 | 289.91 |
| Signed wide (1,327 cases) | 201.16 | 216.81 |

These are instruction counts, not CPU cycles. Wide cases incur additional guards;
the mixture of operands in gameplay determines whether the overall change helps.
The native game build and gameplay validation are pending. Existing rendering
settings and worker ownership are unchanged.

Run `python3 tools/test_div32.py` or `make -C recomp/host test-div32`.
For sanitizer checking, set
`DIV32_TEST_CFLAGS="-fsanitize=address,undefined -fno-omit-frame-pointer"`
when invoking the Python runner. No owned game executable is needed for these
tests. Private ARM fixtures and reports are preserved outside Git under
`2026-09-13-worker-sizing/validation/hardware-updater-20260914T122650Z/div32`.
