## Vita compilation probe

The native fork's **unmodified** `source/math/matrix_math.c` compiled successfully
to an ELF32 ARM EABI5 relocatable object using clang targeting `arm-vita-eabi`,
Cortex-A9/Thumb/hard-float, and the installed VitaSDK sysroot.

Private evidence: `halo-ce-universal/build/vita-probe/`:

- `matrix_math.o`, `matrix.log`, and `attempt.json` (exact compiler command/result).
- `semantics.h`, generated by upstream `tools/linux_msvc_semantics.py`.
- Probe-only `prefix.h`: permits an explicit HALO_VITA target, uses ISO C headers
  before undefining libc macros that conflict with the game's enum names.
- `StdDef.h`: case-spelling shim for `<stddef.h>`.

Flags retain MSVC extensions, short wchar, common symbols, signed char, and
disable strict aliasing. This is **compilation only**: it does not prove runtime
correctness, whole-engine ABI compatibility, linking, or performance.

## Remaining port work

1. Supply compatible SDK headers and game data, then establish a working native
   reference build before attributing failures to Vita changes.
2. Add an ARM32 Vita build graph and verify pointer, struct/union return,
   alignment, floating-point and libc assumptions across the engine.
3. Replace the OpenGL renderer/platform backend with a Vita backend or connect
   native engine calls to Xita's GXM implementation through a deliberate API
   adapter. Xita's existing translated guest-call entry points are not a native
   source ABI. SDL3 headers and library are installed locally, but that alone
   does not supply the upstream GL4.5/GLES3 rendering features.
4. Replace fixed-address Linux mmap allocation and mprotect/SIGSEGV texture-write
   tracking with supported Vita memory/resource tracking. Adapt files, threading,
   audio, input and startup to Vita APIs.
5. Link and package as a separate experimental application; validate startup and
   map loading before a hardware gameplay/performance claim.

No proprietary assets or upstream source are added to this repository. Provenance
and component licenses need review before any source integration/distribution.
