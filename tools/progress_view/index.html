Reading the map

Coverage needs context.

Translated means the generated function has no recorded unsupported-instruction handler. Native helper present means an entry hook can use a native replacement; the original fallback may still run.

Instruction gaps mark functions containing an unsupported handler. Some may be unreachable or discovered from data; this is a review queue, not a count of confirmed gameplay bugs. Boundaries are referenced HLE and kernel APIs, whose implementation coverage is not established by this report.

Area represents distinct emitted instruction markers within each function, with a minimum of one unit per entry. Shared code can appear in multiple functions. These counts do not measure whole-binary coverage, exact decompilation matching, hardware performance, or successful completion of the game.

Exact-match and per-function behavioral validation remain unrecorded until supporting evidence is attached. Each report belongs to one executable revision. Profiles appear in the selector when their reports are added; a profile alone does not establish gameplay support.
